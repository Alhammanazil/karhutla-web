# Api yang Dipelihara

Halaman satu halaman interaktif (ID/ENG) yang menjelaskan akar masalah kebakaran hutan dan lahan (karhutla) di Indonesia.

**Live:** https://karhutla-ochre.vercel.app

- Statis: `index.html` + `favicon.svg`, tanpa build step.
- Narasi berdasarkan video "Pahami Akar Masalah Kebakaran Hutan" (Second Thoughts, riset Formis.id), dilengkapi sumber lain yang tercantum di footer halaman.
